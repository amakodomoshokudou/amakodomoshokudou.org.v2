# 環境変数の設定(astro:env スキーマ化)

## 背景

microCMS 用の環境変数 `MICROCMS_SERVICE_DOMAIN` / `MICROCMS_API_KEY` が `import.meta.env` で直接参照されており、未設定時の挙動が不定だったため、`astro.config.ts` の `env` フィールドで宣言的に管理する。
