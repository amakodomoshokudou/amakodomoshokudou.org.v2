# 表示に影響しない変更では VRT を実行しない

## 目的

ドキュメントなど表示に影響しない変更での VRT 実行を省き、CI の実行時間とコストを減らす。

- [x] CI の実行条件を変更し、issue や開発用ドキュメントなど、表示に影響しない変更だけの場合は VRT を省く
- [x] 表示に関わるコード・画像・依存関係・VRT 設定などの変更では VRT が実行されることを確認する
- [x] VRT は必須チェックにせず、`paths-ignore` でワークフローを省く方針にする
- [x] CI 上で、除外対象のみの変更では VRT が省略され、表示に関わる変更では実行されることを確認する

## 対応内容

`issues/`、`.agents/`、`.vscode/`、ルートの `README.md`・`AGENTS.md` のみの変更では VRT を省く。それ以外のファイルは対象とし、ページ生成に使う Markdown を一括で除外しない。手動実行は引き続き可能とする。
