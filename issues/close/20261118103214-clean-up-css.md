# CSS をきれいにする

Tailwind CSS から純粋な CSS への移行（`issues/close/20261111210925-replace-tailwind-with-css.md`）で残った暫定対応を整理する。

フォーカス表示は従来の `:focus` 定義を維持する。

## reset.css の影響確認

- [x] font-size, font-weight, line-heightはテキストを表示するすべての要素で明示
- [x] `a`: `text-decoration` と `color` を明示する
- [x] `ol` / `ul`: `padding` と `list-style` を明示する
- [x] `button`: `background-color` と `color` を明示する
- [x] `dialog`: UA の padding と border を対処する
- [x] `iframe`: `display: block` と `border: 0` を明示する
- [x] 全要素の `padding` / `border`: 全要素リセットがなくなり UA デフォルトが残る。上記の `dialog` や `button` 以外に影響がないか確認する
- [x] `html` / `:root`: `line-break: strict`、`text-spacing-trim: trim-start`、`text-autospace: normal`、`overflow-wrap: anywhere`、`word-break: normal` を適用し、日本語の折り返し・字間を全ページ VRT で確認する
- [x] `scrollbar-gutter: stable` はデスクトップの左右の領域を個別にスクロールさせる構成に不要なため、`:root` では無効にする。
- [x] `time`: `text-autospace: no-autospace` を適用した状態を全ページ VRT で確認する
