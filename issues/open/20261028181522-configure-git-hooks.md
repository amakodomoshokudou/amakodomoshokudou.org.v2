# コミット時・push 前の Git hooks を整備する

## 目的

ローカルで必要なチェックを自動実行し、確認漏れや CI での手戻りを減らす。

## TODO

- [ ] 既存のチェックと実行コストを整理し、`pre-commit`・`pre-push` で実行する内容を決める
- [ ] 追加のパッケージやツールに依存せず、Git 標準の hooks で実装し、設定をリポジトリで共有する
- [ ] `package.json` の `prepare` スクリプトで Git hooks をセットアップする
- [ ] `pre-commit` にコミット対象の軽量なチェック、`pre-push` に必要な軽量の追加チェックを設定する
- [ ] VRT などの高コストなチェックは CI のみで実行し、Git hooks では実行しない
- [ ] チェック失敗時にコミット・push が停止し、修正内容を判断できることを確認する
- [ ] hooks の導入・更新手順を開発用ドキュメントに記載する
