Tailwind CSS から純粋な CSS への移行（`issues/open/20261111210925-replace-tailwind-with-css.md`）で移行中の暫定対応や見送った整理を、独立した品質改善として行う。

## reset.css 切り替えで影響が出る要素（現在使用中）

`_reset.css` から `reset.css` へ切り替えたことで、現在使用している次の要素に差分が出る可能性がある。全ページ VRT で確認し、意図しない差分はコンポーネント側のスタイルで補う。

- [x] font-size, font-weight, line-heightはテキストを表示するすべての要素で明示
- [x] `a`: `text-decoration` と `color` を明示する
- [x] `ol` / `ul`: `padding` と `list-style` を明示する
- [x] `button`: `background-color` と `color` を明示する
- [ ] `dialog` / `::backdrop`: UA の padding と border が残る。`menu_dialog` の内側余白・枠線と、スクロール連鎖の挙動を確認する
- [ ] `iframe`: `display: block` がなくなり inline に戻る。`video_player` の余白・レイアウトを確認する
- [ ] 全要素の `padding` / `border`: 全要素リセットがなくなり UA デフォルトが残る。上記の `dialog` や `button` 以外に影響がないか確認する
- [ ] `html` / `:root`: `scrollbar-gutter: stable`、`line-break: strict`、`text-spacing-trim`、`text-autospace` などが追加される。スクロールバー分の余白と日本語の折り返し・字間を確認する
- [ ] `time`: `text-autospace: no-autospace` が適用される。日本語の字間への影響を確認する

`img` / `video` / `summary` も使用しているが、今回の差分では実質的な変化はないと判断している。
