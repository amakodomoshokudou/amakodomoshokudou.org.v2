## reset.css 切り替えで影響が出る要素（現在使用中）

`_reset.css` から `reset.css` へ切り替えたことで、現在使用している次の要素に差分が出る可能性がある。全ページ VRT で確認し、意図しない差分はコンポーネント側のスタイルで補う。

全ページ VRT では `dialog` 内のテキスト色の差分のみが発生した。`color` を継承に頼らずコンポーネント側で明示して解消した。それ以外に意図しない差分はない。

`html` / `:root` の `scrollbar-gutter`、`line-break`、`text-spacing-trim`、`text-autospace`、`overflow-wrap` と、`time` の `text-autospace` は、影響を確認できるまで `reset.css` 内でコメントアウトして無効にしている。有効化するときに改めて確認する。

- [x] font-size, font-weight, line-heightはテキストを表示するすべての要素で明示
- [x] `a`: `text-decoration` と `color` を明示する
- [x] `ol` / `ul`: `padding` と `list-style` を明示する
- [x] `button`: `background-color` と `color` を明示する
- [x] `dialog`: UA の padding と border を対処する
- [x] `iframe`: `display: block` と `border: 0` を明示する
- [x] 全要素の `padding` / `border`: 全要素リセットがなくなり UA デフォルトが残る。上記の `dialog` や `button` 以外に影響がないか確認する
- [ ] `html` / `:root`: `scrollbar-gutter: stable`、`line-break: strict`、`text-spacing-trim`、`text-autospace`、`overflow-wrap: anywhere` などが追加される。スクロールバー分の余白と日本語の折り返し・字間を確認する（今回はコメントアウトして無効にしている）
- [ ] `time`: `text-autospace: no-autospace` が適用される。日本語の字間への影響を確認する（`text-autospace` を無効にしているため、有効化するときに確認する）

`img` / `video` / `summary` も使用しているが、今回の差分では実質的な変化はないと判断している。
