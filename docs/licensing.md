# ライセンス

外部素材のライセンス本文と著作権表示は `public/LICENSES/` に置き、サイトから参照できるようにする。

Material Icons（Google Fonts）由来のアイコンは `public/assets/icons/` に SVG ファイルとして置き、`public/LICENSES/material-design-icons-LICENSE.txt` に帰属を記載する。favicon とロゴは独自デザインのため対象外とする。

リセット CSS は kiso.css を参考・改変している。帰属は `src/shared/reset.css` に記載し、ライセンス本文は `public/LICENSES/kiso.css-LICENSE.txt` に置く。
